# ربات کافی‌نت و لوازم‌التحریر حربی

ربات تلگرامی فارسی با منوی «درباره ما»، «خدمات کافی‌نت»، «لوازم‌التحریر» و «تماس با ما».

## راه‌اندازی در Render با گوشی

1. مخزن را در Render از طریق **New + → Web Service** متصل کنید.
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
4. دو متغیر محیطی تعریف کنید:
   - `BOT_TOKEN`: توکن دریافتی از BotFather؛ آن را در کد یا فایل عمومی قرار ندهید.
   - `WEBHOOK_SECRET`: یک رشته محرمانه تصادفی شامل حروف انگلیسی و اعداد، حداقل 32 کاراکتر.
5. Deploy کنید. برنامه هنگام شروع، webhook تلگرام را به آدرس سرویس Render متصل می‌کند.
6. آدرس سرویس را باز کنید؛ پاسخ JSON با status برابر ok باید دیده شود. سپس در تلگرام به ربات `/start` بفرستید.

## نکات امنیتی

- توکن ربات را فقط در Environment Variables سرویس میزبانی قرار دهید.
- اگر توکن قبلاً عمومی شده است، از BotFather آن را تعویض کنید.
- پلن رایگان ممکن است سرویس را در دوره‌های بی‌کاری متوقف کند؛ در این حالت پاسخ‌گویی می‌تواند با تأخیر شروع شود.
